I'm **Arjun Pramanik**, a computer science undergraduate at **George Washington University**. I'm interested in how intelligent models are built and trained—and in making the tools around them more useful.

I build open-source developer tools, experiment with applied AI, and tinker with my homelab. I care about privacy, thoughtful engineering, and asking *who benefits?* before getting caught up in *how does it work?*

## Selected work

- **[OpenCode Plugins](https://github.com/capyBearista/opencode-plugins)** — Independently installable extensions for OpenCode: agent and command discovery, code reviews, output styles, navigation, and more.
- **[YouTube Content Digest](https://github.com/capyBearista/yt-content-digest)** — A Python pipeline that transcribes and summarizes videos, playlists, and channels using local or hosted language models.
- **[Phish-Net](https://github.com/capyBearista/phish-net)** — A local-first phishing email analyzer built with Ollama, keeping email analysis on your machine.
- **[Alien Detector](https://github.com/capyBearista/alien-detector)** — A playful, collaborative computer-vision project using hand landmarks to classify very suspicious-looking hands. 👽

Other tinkering: [self-hosting and Docker Compose](https://github.com/capyBearista/home-server) · [a dark-mode userscript for Artificial Analysis](https://github.com/capyBearista/artificial-analysis-dark-mode).
